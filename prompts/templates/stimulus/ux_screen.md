# UX Screen (모바일 화면) FGI 가이드 베이스

진단 축: 첫인상·발견용이성·이해·신뢰·이탈

## 섹션
1. warmup — 평소 모바일뱅킹 사용 방식, 가장 자주 쓰는 기능
2. first_glance — 화면 무음 30초 노출 → 무엇을 위한 화면인지, 어떤 인상
3. comprehension — 화면 요소 명명(버튼·문구·아이콘) 그리고 의미 추측
4. task_walkthrough — 시나리오(예: "이 상품을 가입하려면 어떻게 누르겠나요?")
5. trust_pain — 신뢰감/불안감 주는 요소, 이탈하고 싶은 지점
6. closing — 한 가지 바꾸고 싶은 것, 다음 화면에 무엇이 있어야 할지

## 질문 슬롯
- {screenAttachments}: 화면 이미지/설명 N장
- {targetTask}: 검증하려는 핵심 작업(가입/송금/조회 등)
