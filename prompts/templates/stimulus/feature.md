# Feature (앱 기능 추가/제거/변경) FGI 가이드 베이스

진단 축: 가치·이해·사용빈도·페인

## 섹션
1. baseline — 기존에 비슷한 기능을 어떻게 쓰는지(타사 포함)
2. exposure — 신기능 노출(이름·설명·동작 흐름)
3. usefulness — 본인 일상에 가치가 있는지, 누구에게 가장 유용할지
4. usage_scenario — 실제 사용 시나리오 상상해 보기
5. concerns — 보안·프라이버시·실수 우려, 신뢰 영향
6. closing — 추가/수정/제거하고 싶은 부분

## 질문 슬롯
- {featureName}, {featureFlow}: 동작 흐름 단계
- {permissions}: 요구되는 권한·동의
